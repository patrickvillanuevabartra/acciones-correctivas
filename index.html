¿Cómo leer este tablero? (guía rápida)

Acción correctiva (AC)

Se abre cuando se detectó un incumplimiento (una «no conformidad»), por ejemplo en una auditoría. Busca eliminar la causa para que el problema no se repita.

Oportunidad de mejora (OM)

Se abre cuando no hay incumplimiento, pero algo puede hacerse mejor. Por eso no lleva análisis de causa raíz.

Plan de acción

Es la lista de actividades concretas, cada una con su responsable y su fecha. La barra de cada tarjeta muestra cuántas ya se hicieron.

Eficacia

Después de hacer las actividades, se comprueba si realmente resolvieron el problema. Solo entonces el expediente se cierra como «eficaz».

Colores

cerrado eficaz · hecho, falta comprobar · en ejecución · plan por aprobar.

Para ver el detalle

Haga clic en «Ver detalle» de cualquier tarjeta. Para cambiar datos, use «Editar» (requiere ingresar con la clave de edición).

¿En qué etapa están los expedientes?

Cada color es una etapa. Haga clic en una etapa para ver solo esos expedientes.

¿Dónde se originan los problemas?

Agrupa las acciones correctivas por su tipo de causa. Una barra larga indica una causa que se repite. Verde: ya resueltas; naranja: en curso.

Próximas fechas a cumplir

Actividades aún no terminadas, ordenadas por su fecha programada. En rojo: ya pasó la fecha.
