¿Qué significa cada término? Guía rápida

Acción correctiva (AC)

Se abre cuando se detectó un incumplimiento (una «no conformidad»), por ejemplo en una auditoría. Busca eliminar la causa para que el problema no se repita.

Oportunidad de mejora (OM)

Se abre cuando no hay incumplimiento, pero algo puede hacerse mejor. Por eso no lleva análisis de causa raíz.

Plan de acción

Lista de actividades concretas, cada una con responsable y fecha. La barra de cada expediente muestra cuántas ya se hicieron.

Eficacia

Después de hacer las actividades, se comprueba si realmente resolvieron el problema. Solo entonces el expediente se cierra como «eficaz».

Usuarios con permiso para editar

Solo pueden ingresar al aplicativo las personas de esta lista, activas y con clave. Los editores crean y editan expedientes; solo los administradores archivan, restauran y gestionan usuarios. Para quitar el acceso a alguien, márquelo como «Inactivo»: su historial se conserva.

Ingrese como administrador para ver los usuarios.

Bitácora de cambios

Registro automático de cada ingreso, expediente creado, editado, archivado o restaurado, y de los cambios de usuarios. No se puede modificar desde el aplicativo; sirve como evidencia ante una auditoría.

Ingrese como administrador para ver la bitácora.

Expedientes archivados

Los expedientes archivados no se cuentan en los indicadores ni aparecen en la lista principal, pero se conservan. Puede devolver cualquiera a la lista de vigentes.
