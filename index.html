¿Qué significa cada término? Guía rápida

Acción correctiva (AC)

Se abre cuando se detectó un incumplimiento (una «no conformidad»), por ejemplo en una auditoría. Busca eliminar la causa para que el problema no se repita.

Oportunidad de mejora (OM)

Se abre cuando no hay incumplimiento, pero algo puede hacerse mejor. Por eso no lleva análisis de causa raíz.

Plan de acción

Lista de actividades concretas, cada una con responsable y fecha. La barra de cada expediente muestra cuántas ya se hicieron.

Eficacia

Después de hacer las actividades, se comprueba si realmente resolvieron el problema. Solo entonces el expediente se cierra como «eficaz».
